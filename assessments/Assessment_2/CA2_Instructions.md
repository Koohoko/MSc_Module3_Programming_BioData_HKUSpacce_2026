## Assessment Tasks

Students are given a `biomarker_validation` dataset (generated uniquely from their Student ID) containing:
- `Level`: Biomarker measurement (continuous)
- `Group`: Case or Control

### Task 1: Calculate Sensitivity & Specificity (15 pts)
At a cutoff of 5.0, calculate:
- Sensitivity
- Specificity

### Task 2: Perform T-test (15 pts)
Test if biomarker levels differ significantly between Cases and Controls.

### Task 3: Generate ROC Curve (15 pts)
- Use pROC to create an ROC curve
- Report the AUC value

### Task 4: Interpretation (15 pts)
Briefly interpret: Is this a good diagnostic test?

### AI Interaction (20 pts)
Document prompts and responses.

### Reflection (20 pts)
Answer reflection questions.
