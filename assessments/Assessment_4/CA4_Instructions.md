## Assessment Tasks

Students are given a tree object and metadata (generated uniquely from their Student ID).

### Task 1: Create Rectangular Tree with Labels (15 pts)
- Use ggtree() and geom_tiplab()

### Task 2: Color Tips by Location (15 pts)
- Attach metadata with %<+%
- Color tip labels by Location column

### Task 3: Create Circular Layout (15 pts)
- Change layout to "circular"

### Task 4: Add Scale Bar and Export (15 pts)
- Add geom_treescale()
- Export as PNG using ggsave()

### AI Interaction (20 pts)
Document prompts and responses.

### Reflection (20 pts)
Answer reflection questions.
